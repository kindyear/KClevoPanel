# KClevoPanel v0.14.0

- 托盘左键直接打开主窗口，右键打开实时小面板。
- 小面板与主菜单设置下方提供红色「退出程序」，均须二次确认；取消为默认按钮。
- 标题栏保留最小化与最大化/还原，移除关闭按钮。最小化继续后台监测。
- MSI按当前用户安装到 `%LOCALAPPDATA%\Programs\KClevoPanel`，添加开始菜单快捷方式；不安装驱动，不默认开启自启动。升级/卸载前请先从应用确认退出。
- 另提供自包含Windows x64便携ZIP与SHA256SUMS.txt。

仅验证COLORFUL X17 AT 23H2 / BIOS 1.07.04TCOLO及指定桥驱动和接口库，其他机型不得直接套用控制。安装包未进行代码签名。固件控制的适配限制与验证范围见仓库README。
